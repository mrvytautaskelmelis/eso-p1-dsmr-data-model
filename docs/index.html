ESO P1 smart meter data model vs DSMR 5.0.2

Data model of the P1 port on smart meters of the Lithuanian grid operator ESO (AB „Energijos skirstymo operatorius“), cleaned up and compared with the Dutch DSMR 5.0.2 P1 Companion Standard, which ESO declares it follows.

Downloads

FileContent
P1_duomenu_modelis_v32.xlsxAll ESO OBIS codes with telegram sets (Standard / Extended / Maximum), English and Lithuanian descriptions, units, example values with precision, value formats and DSMR 5.0.2 status; DSMR format codes, COSEM data types, Class ID / tag table; ESO example telegrams.
P1_ESO_vs_DSMR_coverage_v1.xlsxWhich DSMR 5.0.2 objects ESO sends in which telegram set, with findings.

Key findings

  • ESO Standard set omits export (generation) data that DSMR always includes: 1-0:2.8.1, 1-0:2.8.2, 1-0:2.7.0, 1-0:22/42/62.7.0.
  • ESO Maximum set omits total power 1-0:1.7.0 / 1-0:2.7.0.
  • 1-0:52.36.0 is marked Standard in the ESO profile table but missing from the ESO Standard example telegram.
  • Not sent by ESO: 1-3:0.2.8, 0-0:96.14.0, 0-0:96.7.9, 1-0:99.97.0.
  • 72 ESO objects are extensions outside DSMR 5.0.2 (reactive/apparent energy and power, power factor, averages, demand registers, sag/swell duration and magnitude, firmware).
